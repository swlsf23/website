## Site pessoal

Este site é uma aplicação React no cliente (Vite, TypeScript) com conteúdo em Markdown gerado no build.

Os recursos na AWS são geridos com Terraform. O GitHub Actions faz build e deploy a cada push para `main`. O site está hospedado no S3 e no CloudFront.

O currículo e os textos de exemplo usam o mesmo Markdown para o site e para a exportação PDF: marked para HTML, Playwright com Chromium para o PDF, CSS para o layout.
