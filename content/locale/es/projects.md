## Sitio personal

Este sitio es una aplicación React en el cliente (Vite, TypeScript) con contenido en Markdown generado en el build.

Los recursos en AWS se gestionan con Terraform. GitHub Actions compila y despliega en cada push a `main`. El sitio está alojado en S3 y CloudFront.

El currículum y los textos de ejemplo usan el mismo Markdown para el sitio y para la exportación PDF: marked para HTML, Playwright con Chromium para el PDF, CSS para el diseño.
