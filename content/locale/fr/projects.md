## Site personnel

Ce site est une application React côté client (Vite, TypeScript) dont le contenu rédigé en Markdown est généré au moment du build.

Les ressources AWS sont gérées avec Terraform. GitHub Actions construit et déploie à chaque push sur `main`. Le site est hébergé sur S3 et CloudFront.

Le CV et les textes d’exemple utilisent le même Markdown pour le site et pour l’export PDF : rendu HTML avec marked, Playwright avec Chromium pour le PDF, CSS pour la mise en page.
